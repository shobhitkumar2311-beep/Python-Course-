## 📡 Overview

A personal, ever-growing collection of Python practice problems and mini-projects — worked through chapter by chapter, from the absolute basics up to object-oriented programming. Every solution is a standalone, runnable script with the original problem statement kept as a comment at the top of the file, so this repo doubles as a study log and a quick-reference bank.

<br/>

## ⚡ Quick Start

```bash
# clone the repo
git clone https://github.com/Anucodex21/python-course-github.git
cd python-course-github

# run any problem directly — each file is standalone
python Chapter-01/Problem01.py
```

> **Note:** a few `Chapter-09` file-handling scripts read/write sample text files (`poem.txt`, `hiscore.txt`, etc.) that live alongside them in that folder. Run those scripts from *inside* `Chapter-09/`, or adjust the file paths in the script, so they can find their inputs.
